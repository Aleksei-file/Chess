# Chess

Chess web application built with Next.js, where the user plays against the Stockfish engine. The project is under active development; the rules are handled by chess.js and games are persisted in SQLite on the server.

## Running

Requires Node.js and npm. From the repository root:

```bash
npm run install:all
npm run dev
```

This starts the server and the Next.js client in development mode; open the address printed by the client (by default http://localhost:3000).
